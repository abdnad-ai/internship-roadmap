## What I Learned From AI Assistance

* App Router routes need page.js files inside route folders.
* Reusable components help keep dashboard pages consistent.
* Tailwind CSS can be used directly inside JSX for fast UI building.
* NestJS uses modules, controllers, and services to organize backend code.
* CRUD skeleton routes can be created before connecting a database.
