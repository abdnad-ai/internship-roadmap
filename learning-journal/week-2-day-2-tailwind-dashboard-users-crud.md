## NestJS Users CRUD Skeleton

I created a NestJS backend project for users CRUD practice.

Backend structure practiced:

* Users module
* Users controller
* Users service
* GET all users route
* GET single user route
* POST create user route
* PATCH update user route
* DELETE remove user route

## What I Learned

* App Router pages are created using folders inside the app directory.
* Each route needs its own page.js file.
* Shared components make frontend code easier to reuse.
* NestJS separates backend logic into modules, controllers, and services.
* CRUD skeletons help plan backend structure before adding a real database.
