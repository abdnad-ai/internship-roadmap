## What I Learned

* Next.js App Router uses the app folder for routes and layouts.
* page.js represents a route page.
* layout.js provides shared structure for pages.
* Server components are default in Next.js App Router.
* Client components are needed for browser-side interactivity.
* NestJS uses modules, controllers, and services to organize backend code.
* Controllers handle routes, while services contain logic.
